# Cognifyz Railway Data Engineering

**Internship Project | Cognifyz**

This project focuses on exploring, cleaning, transforming, and analyzing railway data using Python.

## Project Tasks

### Task 1: Data Exploration and Basic Operations
- Load and inspect the railway dataset.
- Calculate basic statistics.
- Identify common source and destination stations.
- Clean and standardize the data.

### Task 2: Data Transformation and Aggregation
- Filter trains by operating days and source stations.
- Group trains by source station.
- Calculate average trains per day.
- Categorize trains as Weekday or Weekend.

### Task 3: Advanced Data Analysis
- Analyze weekly train distribution.
- Identify source and destination station patterns.
- Explore correlations between days and train counts.
- Generate insights and recommendations.

### Task 4: Data Visualization and Reporting
- Create charts, plots, and heatmaps.
- Visualize station and day-wise train distribution.
- Prepare a report containing findings and insights.
